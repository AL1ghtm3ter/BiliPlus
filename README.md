# 小电视助手 · BiliPlus

**3.1.0 · Public Beta · 浏览器工具版**

给 B站网页版补上无级倍速、换一换历史、封面查看、悬停预览、评论公开属地、右侧评论与界面净化。

本版已删除 AI 助手，包括字幕与总结面板、问答、广告片段识别与自动跳过、整理成文、语音转写和本机模型配置。扩展直接在浏览器运行，不需要模型、账号或本机桥接。

## 下载与安装

1. 从 [3.1.0 发布页](https://github.com/AL1ghtm3ter/BiliPlus/releases/tag/v3.1.0)下载 `BiliPlus-3.1.0-source.zip` 并完整解压。
2. 打开 `chrome://extensions`，启用“开发者模式”，点击“加载已解压的扩展程序”。
3. 选择解压后的 **`BiliPlus/extension` 文件夹**，确认名称“小电视助手 · BiliPlus”、版本 **3.1.0**。
4. 刷新 B站标签页，点击扩展图标，按需开启功能。所有功能开关首次默认关闭。

需要 Chrome 120 或更新版本。使用扩展无需安装 npm、Node 或其他本机程序。

## 从 3.0.x 更新

先在旧版设置导出配置备份。保留旧目录，把新源码解压到另一个目录，再在扩展管理页切换到新 `extension` 路径，确认版本为 3.1.0，并刷新所有已打开的 B站标签页。旧页面刷新后才会移除已运行的助手面板。

扩展标识保持不变；同一浏览器配置内保留播放器、首页、布局、筛选、净化和外观设置。也可以导入旧版配置备份：保留上述偏好，忽略已删除的 AI 字段与相关收藏开关。更新安装时清理旧助手缓存和诊断记录。

此前安装的模型和本机软件由用户自行管理；更新扩展不会卸载它们，新版没有调用这些组件的接口。

## 功能

- **播放**：原生菜单内的 0.1–5 倍速滑杆、预设与自定义快捷键；全屏控制栏收起后的进度条。
- **布局**：把评论移到播放器旁，支持调节宽度，关闭后还原原生节点。
- **首页**：换一换历史、悬停简介与预览时间轴、封面原图、加载优化、可设置背景的极简搜索首页。
- **筛选与净化**：标题、UP、UID、播放数据和日期规则；广告、推广、直播等卡片过滤；按项隐藏热搜、轮播、推荐与弹幕等区域。
- **偏好**：浅色/深色/系统主题、常用功能固定、配置备份、本地背景。

首页历史只记录当前首页会话实际展示过的批次；评论属地只展示 B站公开返回且可匹配的字段。筛选和净化仅改变本地网页，不执行账号拉黑操作。广告卡片过滤保留，视频口播广告的模型识别与跳过已删除。

功能和默认值见 [FEATURES.md](FEATURES.md)，维护结构见 [ARCHITECTURE.md](ARCHITECTURE.md)。

## 数据与权限

扩展使用 `storage` 保存设置和本地背景，访问 `api.bilibili.com` 获取视频信息与预览数据，并在 B站主站、搜索页运行内容脚本。图片直接通过站点 CDN 显示，远程背景会由浏览器请求所填 HTTPS 地址。本版不申请 `nativeMessaging` 权限，不连接本机或云端模型，不下载音轨。

配置备份不包含浏览器账号。站点内容仍受账号可访问范围及内容权利约束。

## 开发与验证

开发工具使用 Node.js 24 和锁定的 npm 依赖：

```sh
npm ci
npm run check
npm run format:check
npm test
npm run build
npm run package
```

构建在 `dist/extension` 生成可加载源码，打包在 `dist/BiliPlus-3.1.0-source.zip` 生成完整源码包及逐文件 SHA256 清单。源码包不包含开发依赖、浏览器配置、运行时、模型或本机安装脚本。

这是公开测试版。源码回归和浏览器检查的范围见 [RELEASE-TESTS.md](RELEASE-TESTS.md)；模拟检查不能替代真实 B站所有功能组合验收，页面改版仍可能需要适配。
