# 小电视助手 · BiliPlus

**3.0.1 · Public Beta（发布候选）**

给 B站网页版补上更顺手的播放和浏览工具：无级倍速、左右分屏、换一换历史、界面净化、评论公开属地，以及封面查看。视频页的字幕面板嵌入右栏，支持调节高度和内部滚动。

字幕总结、问答、广告片段识别与整理成文默认使用本机 **Ollama + Qwen3:4b**，无需 Codex 账号。Codex 是可以显式选择的另一种处理方式。本项目的独立源码按 [MIT](LICENSE) 开源；第三方软件、模型及站点内容遵循各自许可，见 [第三方说明](THIRD-PARTY-NOTICES.md)。

这是公开测试版。真实本机模型已通过四类后端任务验证，但无 Node/无 Ollama 的干净 Windows 首次安装，以及真实 Chrome 的所有功能组合，尚未完成验收；B站页面变化也可能需要适配。

## 功能

- **播放**：原生倍速菜单内的 0.1–5 倍速滑杆、预设与快捷键；全屏控制栏收起后的进度条。
- **布局**：播放器旁的分屏入口，详情、合集、评论、字幕助手、弹幕、推荐侧栏；侧栏宽度可调，关闭后还原节点。
- **首页**：换一换历史、悬停简介与预览时间轴、封面查看、加载优化、带背景的极简搜索首页。
- **筛选与净化**：标题、UP、UID、播放数据与日期规则；广告、推广与特殊类型卡片过滤；按项隐藏热搜、轮播、推荐、弹幕等区域。
- **字幕**：读取已有字幕，导出 SRT/TXT/JSON；可选安装本机语音转写；使用所选模型总结、问答或整理文字。
- **偏好**：浅色/深色/系统主题、常用功能固定、配置备份、缓存与诊断维护。

完整分组、默认值与边界见 [FEATURES.md](FEATURES.md)，维护结构见 [ARCHITECTURE.md](ARCHITECTURE.md)。

## 安装

只使用倍速、分屏、首页历史、封面、属地和净化时，在 `chrome://extensions` 开启开发者模式并加载本项目的 `extension` 文件夹即可，不需要 Node、Ollama 或 Codex。读取和导出已有字幕也不需要模型。

需要总结、问答等模型功能时，再按下面步骤安装本机桥接。模型不会随浏览器启动自动下载；安装脚本的模型准备、设置页的下载按钮或首次模型任务才会触发准备。

适用环境：Windows x64、Chrome 120 或更新版本。桥接启动器需要系统 .NET Framework C# 编译器；源码包不附带运行环境或模型权重。

1. 将完整项目文件夹解压到准备长期保留的位置。不要只保留 `extension`。
2. 在项目文件夹打开 PowerShell，手动运行本机桥接安装脚本：

   ```powershell
   powershell.exe -NoProfile -ExecutionPolicy Bypass -File '.\安装本机桥接.ps1'
   ```

   脚本复用已有可运行 Node；没有 Node 时，从 `nodejs.org` 下载 Node 24 LTS Windows x64 便携 ZIP，核对官方 SHA256 清单并检查 ZIP 路径后解压到项目 `.runtime/node`。这一步不修改系统 PATH。桥接仅注册到当前 Windows 用户；若其他目录已占用同名主机，安装会停止。

   随后准备默认文本模型。已有 Ollama/模型会复用；缺失 Ollama 时，下载官方 Windows 安装器，验证 Authenticode 签名及发布者，再安装到当前用户目录，启动并下载模型。终端显示实际阶段与下载进度，`Ctrl+C` 可取消。取消后可重跑脚本或在设置页继续准备。

   默认 [Qwen3:4b](https://ollama.com/library/qwen3:4b) 为约 4B 参数、Q4_K_M 量化，模型文件约 **2.5GB**；运行时、缓存和推理还需额外磁盘及内存。首次准备需要联网，耗时取决于网络和机器。

3. 打开 `chrome://extensions`，启用“开发者模式”，点击“加载已解压的扩展程序”，选择项目中的 **`extension` 文件夹**。安装脚本不会替你完成 Chrome 这一步。
4. 确认扩展名称为“小电视助手 · BiliPlus”、版本为 **3.0.1**。点击扩展图标的“检查本机连接”，分别核对桥接、本机文本模型与可选转写的状态。
5. 刷新 B站标签页。在扩展弹窗开启需要的播放、布局或首页功能；视频右栏默认打开字幕页。先用有字幕的短视频读取字幕，再测试总结。

仅重装桥接、暂不准备模型时：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File '.\安装本机桥接.ps1' -SkipModelSetup
```

桥接可用与模型就绪是两个状态。打开设置中的“字幕与总结”，可选择 `qwen3:1.7b`、`qwen3:4b`、`qwen3:8b`，检查所选模型，或点击“下载并配置本地模型”；界面支持进度和取消。模型准备成功后只保存本次模型选择，其他未保存修改仍需点击“保存设置”。

## 可选处理方式

**Codex**：自行安装并登录 Codex CLI，在设置中明确选择 Codex，再检查连接。该模式会把标题、字幕、问题和所需上下文交给其模型服务，并使用对应账号额度。本机模型失败时不会自动切换 Codex。

**无字幕视频的本机转写**：文本模型不能把音频识别成字幕。需要时先按 [uv 官方说明](https://docs.astral.sh/uv/getting-started/installation/)安装 `uv`，然后单独运行：

```powershell
& '.\安装本机转写.ps1'
```

默认使用 faster-whisper `small`、CPU int8；可加 `-Model base` 选择较小模型。脚本准备 Python 3.11 环境和语音模型，优先复用已有缓存。识别在本机进行，但获取 B站可播放音轨仍需网络及当前账号权限。文本模型准备完成不代表转写已就绪；真实无字幕视频的浏览器自动回退仍待进一步验收。

## 使用与输入限制

字幕读取与导出不需要模型。总结、问答、广告识别、整理成文使用当前明确选择的处理方式；自动任务默认关闭，可分别设置视频时长范围。自动广告跳过有置信度门槛、倒计时和“保留本段”，模型结论可能有误。

**本机模型单次完整 prompt 的 UTF-8 总量最多 28,000 字节**，包括系统和任务提示词、标题、字幕、问题及问答历史；不是 28,000 个汉字。超过限制会明确拒绝，不会静默截断字幕。当前版本不自动拆分长视频，请选择较短分 P。通用字幕输入另有最多 30,000 条、序列化 200,000 字符等校验，不能据此推定本机模型可接收同样大小的内容。

助手底部手柄可拖动调节整体高度，方向键每次调节 40px，双击复位；字幕与结果在内部滚动。字幕完整显示全部条目，点击整行或用键盘激活可跳到对应时间。播放时高亮当前句并在列表内跟随；手动滚动暂缓跟随 5 秒，也可点击“跟随播放”立即恢复。首页历史仅记录当前首页会话中实际展示过的批次，不是跨会话推荐档案。评论属地仅显示 B站公开返回且可匹配的字段。

## 数据与权限

| 操作                           | 数据去向                                                              |
| ------------------------------ | --------------------------------------------------------------------- |
| 视频信息、已有字幕、封面与预览 | B站 API/CDN，使用浏览器当前可访问范围                                 |
| 默认文本分析                   | 本机 `127.0.0.1:11434` 的 Ollama 服务；首次安装和模型下载访问其分发源 |
| 可选 Codex 分析                | 用户自行选择的 Codex CLI 及其模型服务                                 |
| 可选音轨转写                   | 限域下载音轨后本机识别；本次临时文件在完成、取消或报错后清理          |
| 设置、背景、缓存与近期诊断     | 浏览器本地存储和项目本机运行目录；不主动上传                          |

Node 桥接由 Chrome 按需启动，通过 Native Messaging 标准输入/输出通信，没有另设 HTTP 桥接服务。Ollama 自身是独立本机服务。HTTPS 背景图会由浏览器请求所选地址；本地背景在浏览器缩放后保存。配置备份不含账号登录信息、字幕或分析缓存。

## 更新、移动与卸载

更新前可在设置页导出配置。更新源码后重跑桥接安装脚本，在 `chrome://extensions` 重新加载扩展，并刷新 B站标签页。磁盘版本更新不代表 Chrome 已加载；请核对弹窗与本机桥接版本。

移动目录前，在旧目录运行 `卸载本机桥接.ps1`；移动后从新目录重新安装，并让 Chrome 加载新 `extension` 路径。装过 ASR 的还需重新运行转写安装脚本以更新绝对路径。卸载脚本只移除属于当前目录的桥接注册，不删除 Ollama、模型或项目文件。

## 常见问题

| 情况                       | 处理                                                                             |
| -------------------------- | -------------------------------------------------------------------------------- |
| 找不到本机桥接             | 在当前完整项目目录重跑安装脚本，确认没有被另一目录占用；重新加载扩展并刷新网页   |
| 桥接正常，模型未就绪       | 在设置检查当前所选模型，使用下载配置按钮，查看具体阶段或错误                     |
| 生成超时或输入过长         | 冷启动和 CPU 推理可能较慢；选择较短分 P，保留原错误信息；单次生成默认最多 5 分钟 |
| 字幕/音轨请求被拒绝        | 先登录并确认当前账号能播放该内容；本扩展不绕过会员、付费或区域权限               |
| 缩略图、布局或原生控件异常 | 关闭相关功能并刷新，排查其他同时改页面的扩展；B站改版可能需要适配                |
| 筛选后没有内容             | 放宽规则；连续三批全隐藏会暂停规则过滤，独立广告/类型开关仍生效                  |

## 开发与验证

开发需要可从终端使用的 Node/npm。项目运行不需要安装 npm 依赖；测试与格式工具依赖可由锁文件安装：

```powershell
npm ci
npm test
npm run check
npm run format:check
npm run build
npm run package
```

测试包含模拟 DOM、Chrome API 替身、原生消息和 Windows 安装脚本隔离测试；不能替代真实站点验收。现有机器已实际运行桥接安装的 `-SkipModelSetup` 路径并复用原有 Node。实际 Windows EXE → NativeHost → Ollama Qwen3:4b 已用合成中文字幕通过总结、问答、广告识别、整理成文四类任务；这不是干净机器完整安装、Chrome 实页点击验收或全视频准确率评测。完整边界见 [测试与发布说明](RELEASE-TESTS.md)。

`npm run package` 生成 `dist/BiliPlus-3.0.1-source.zip`。公开源码使用明确白名单，保留完整可读源码、[架构](ARCHITECTURE.md)、[功能](FEATURES.md)、[更新记录](CHANGELOG.md)、[MIT 许可](LICENSE)与[第三方说明](THIRD-PARTY-NOTICES.md)。运行目录、模型、机器配置、旧插件包、派生分析材料及历史个人测试日志不属于公开源码包。
